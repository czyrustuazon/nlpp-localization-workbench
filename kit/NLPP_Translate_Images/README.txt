NLPP UI image audit kit
=======================
Full EngPatcher UI PNG set (~1200 images / ~68 folders): menus, softkeys,
headers, mail, date editor, camera, title, popups, map, shop, profile, …

1. Unzip / keep this folder intact (index.html + media/).
2. Open index.html in Chrome/Edge/Firefox (or use the hub ../index.html).
3. Mark OK / Needs fix, or upload a same-size PNG replacement.
4. Use Preview background (light checker) if transparent text is hard to see.
5. Click Save progress → post nlpp-images-….json in Discord
   #translated-work-to-review
   https://discord.com/channels/1536915629787840572/1545180296343715891

Replacements must match original width x height. Uploads embed as png_b64.
